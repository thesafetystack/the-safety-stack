# Changelog: techniques

## 1.2.0 (draft, 2026-10-30; not released)

- 246 techniques (149 intervention, 32 monitoring, 65 assessment; 1.1.0: 234) and 14 group nodes (1.1.0: 9); 12 techniques and 5 group nodes added; no id removed, merged, renamed or re-pointed.
- Schema `techniques-3`: `meta.layers` (the ten v0.9 dashboard groups, promoted into the file); technique fields `layer` (required), `tags` (`pre-llm`), `counts_when`. The validator checks that every layer is a `meta.layers` id.
- Why layers in the file: The v0.9 dashboard groups were a view outside the file; with them in the file a reader sees where each entry sits, the coverage review has a reference, and the risk-generator families can be mapped onto a published structure.
- sha256 `e6c2515164dbd38bf6f396bf544e9e270b51127f2fdf7fa0a366bbd097450204` (draft; changes with every rebuild).


Change classes in brackets: `extension` (an entry matches more documents; old labels stay correct), `eligibility` (a purpose condition made explicit in `counts_when`; uses without it get no row), `clarification` (wording or moved text, same meaning), `policy` (an annotation rule changes), `name`, `status`. Classes are assigned by rule from the edit and checked by hand.
